# Python

## Charakterystyka
Python to czytelny, dynamicznie typowany język programowania. Pozwala korzystać
z programowania proceduralnego, obiektowego i funkcyjnego, dlatego nie wymaga
umieszczania każdej operacji w klasie.

## Zastosowania
Python jest często wykorzystywany w automatyzacji, analizie danych, backendach
oraz projektach związanych ze sztuczną inteligencją. Jego ekosystem zawiera
biblioteki do pracy z modelami językowymi, danymi i usługami HTTP.

## Środowiska wirtualne
Każdy projekt powinien posiadać osobne środowisko wirtualne. Izoluje ono
zależności projektu od pakietów systemowych i innych aplikacji. Narzędzie uv
może tworzyć środowisko, instalować zależności i uruchamiać kod zgodnie z
konfiguracją zapisaną w pliku pyproject.toml.

## Type hints
Adnotacje typów opisują oczekiwane argumenty i wartości zwracane przez funkcje.
Python nie wymusza ich podczas zwykłego wykonania programu, ale edytory i
narzędzia do statycznej analizy mogą dzięki nim wcześniej wykrywać błędy.
