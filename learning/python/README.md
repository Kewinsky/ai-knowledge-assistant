# Python for AI Engineering

This is the Python knowledge track supporting the AI Engineer path. The topic inventory is based on the [roadmap.sh Python roadmap](https://roadmap.sh/python), then prioritized for an experienced Software Engineer moving into AI Engineering.

## Material format

Every completed topic has:

1. a compendium in `topics/` with theory, examples, pitfalls and control questions;
2. a specification in `exercises/`;
3. learner-written code reviewed before the next topic;
4. a short distilled note copied to Notion after completion.

`Core` means required before the first AI Engineer applications. `Selective` means learn the listed practical subset. `Later` means return when a project or job description requires it.
